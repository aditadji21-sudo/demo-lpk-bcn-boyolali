# Demo — LPK Bina Cerdas Nusantara (Boyolali)

Landing page satu halaman untuk lembaga pelatihan kerja ke Jepang.

**Demo live:** https://demo-lpk-bcn-boyolali.vercel.app

## Status

Ini **demo portofolio desain web**, bukan situs resmi lembaga. Halaman
diberi `noindex, nofollow` dan banner penanda agar tidak bersaing dengan
situs asli lembaga di mesin pencari.

Angka biaya, rentang gaji, nomor batch, dan testimoni pada demo ini masih
berupa placeholder dan belum diverifikasi — jangan dijadikan acuan.

## Teknis

- Next.js 14 static export, Tailwind CSS
- Palet diambil dari logo lembaga: navy `#0C2484`, oranye-emas `#FC9C0C`
- Gate kontras WCAG berbasis piksel: 25 elemen teks diperiksa, 0 gagal
- Tanpa overflow horizontal di 390px / 768px / 1440px
- Font Plus Jakarta Sans variable, dilayankan sendiri (tanpa CDN pihak ketiga)
